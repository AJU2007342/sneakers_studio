# Sneaker's Studio 👟

A sneaker e-commerce website featuring brand categories, collections, trending picks, and a contact form — built with HTML and CSS.

## 📄 Features
- Hero section with full-screen background
- Shop section with brand categories — Nike, Adidas, Puma, Jordan, NB, UA
- Collections page with model listings per brand
- Trending Now section
- Contact form with name, email, and mobile fields
- Footer with social links
